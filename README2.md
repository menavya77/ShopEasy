# ShopEasy - E-Commerce Website
A simple and modern E-Commerce website built with Node.js, Express and HTML/CSS/JS.

## Features
- Product Listing
- Add to Cart
- User Friendly UI
- Responsive Design
- Backend API with Express

## Tech Stack
- Frontend: HTML, CSS, Javascript
- Backend: Node.js, Express.js
- Database: In-memory
